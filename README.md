# PanneauAssociationTesrelou
Panneau pour la distribution des cartes de l'association, ["T'es relou"](https://tesrelou.fr).

Celle ci met à disposition des cartes : celles ci peuvent etre exposées et distribuées  via ce panneau.

Les dimensions sont en mm.

Les mesures sont faites pour des plaques de bois de 10 mm d'épaisseur.

Le prototype a été fait sur une graveuse laser epilog Fusion Pro.
